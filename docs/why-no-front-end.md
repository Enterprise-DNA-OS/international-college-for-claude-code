# Why no front end

The database and CLI run the college back office. Read-only HTML shows attendance, fees and weekly decisions. A coding agent runs the same commands from a plain-language request.

An interactive teacher portal makes mobile roll marking and concurrent access easier. Offline attendance, student self-service, timetabling drag and drop, online applications and payment collection are not included. Enterprise DNA scopes those screens and connections for a custom installation. Embedded PGlite permits one process at a time. A shared PostgreSQL database needs access controls, backups and a deployment design.

The free base does not issue government CoEs, submit PRISMS, AVETMISS, VSL or TCSI returns, validate visas, award qualifications or replace a learning management system. Its evidence worksheets do not certify compliance.
