# Mark attendance

Read `docs/cli.md` and the affected record first. Run `npm run college -- mark <enrolment> --date=YYYY-MM-DD --minutes=240` using the operator's actual values. Never invent evidence. Ambiguous names print candidates and exit 1. Read the record again after a change. Drafts stay in `drafts/` and never send. For imports, inspect the dry run and source counts before the operator authorises the real import.
