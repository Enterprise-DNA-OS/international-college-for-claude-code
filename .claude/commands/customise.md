# Make the college system yours

Read CLAUDE.md, docs/compliance.md and the migrations. Describe the requested field, workflow or policy. Back up and test a migration against disposable data first. Add a numbered SQL migration; never rewrite an applied migration. Update the CLI, affected views and documents and tests. Run npm run migrate and npm test. Do not weaken a legal threshold or treat a local policy as legislation. A production migration requires the operator to approve its concrete effect.
